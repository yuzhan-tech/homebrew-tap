# yuzhan-tech/homebrew-tap

Homebrew tap for [yuzhan-tech](https://github.com/yuzhan-tech) tools.

## Install

```bash
brew tap yuzhan-tech/tap
brew install luatos-tools
```

## Formulae

- **luatos-tools** — Rust CLI for LuatOS firmware packaging, flashing, and serial monitoring. ([source](https://github.com/yuzhan-tech/luatos-tools))

## Updates

Formulae in this tap are updated automatically by the release workflows of their source repositories. Manual edits to `Formula/*.rb` will be overwritten on the next release.
